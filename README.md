# Negative Tweet Detector

A machine learning-based application that detects negative or offensive tweets from user input.

This project was developed as a practice project to improve my ability to make predictions based on data. It also provided practical experience in machine learning, data analysis, and application development.

## Features

- Predicts whether a given text is negative or positive
- Uses a dataset for prediction
- Simple graphical user interface
- Standalone Windows executable available

## How to Run

### Python
Run the `main.py` file from the `tweet` folder.

### Executable
A standalone `.exe` version is available in the **Releases** section.

Download `TweetAnalyzer.exe` and `tweets.csv` from the latest release, place them in the **same folder**, and run `TweetAnalyzer.exe`.
